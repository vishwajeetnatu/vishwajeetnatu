## What I've built

Most of my production work lives in private organisation and client repositories, so the code isn't public. Here is what each system does and what I owned. I'm happy to walk through the architecture of any of them.

### Mood Indigo, IIT Bombay — Web & Tech Head, 55th edition
Asia's largest college cultural festival: 163K+ footfall, 9K+ colleges, 240+ events.

- **My MI Portal:** a multi-tenant platform spanning 7+ portals on a Node.js and MySQL backend that absorbed **165K+ registrations** under peak load, with role-based dashboards over indexed queries.
- **Main website:** led **8+ developers** to ship a 3D site in React.js and Three.js that sustained **20M+ hits**. I owned code review and merges.
- **Security pass system:** QR-based gate entry with an admin scanner, containerised with Docker and cached in Redis for sub-second checks. It cut manual gate effort by **40%**.

- **Mood Indigo app:** React Native app for Android and iOS with login, passes, venue maps and profiles.
- **Infrastructure:** ran production on DigitalOcean behind Nginx, with DNS, SSL and CDN through Cloudflare. I led a 300+ volunteer tech team through live events.

### Infollion Research Services — Software Engineer Intern

- Benchmarked AI output against **927 manually mapped industries** using an LLM-as-judge pass.
